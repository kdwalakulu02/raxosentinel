Release blockers:
1. Archive discovery is incomplete. ZipArchive processes one central directory, not all multiple embedded ZIPs. Marker counts conservatively identify some but do not prove complete inspection of all malformed, ambiguous or nested polyglots. Unsupported-format checks cover recognizable byte signatures, not all possible embedded formats or encodings. False CLEAN remains possible for unrecognized embedded content; do not claim comprehensive support. Implement and validate bounded structural discovery, fail closed when incomplete, and test all requested cases including memory and recovery.
2. The coordinator verdict enum lacks TIMEOUT; worker deadline failure is returned as ERROR. Implement a machine-readable distinct timeout with a compatibility path for current clients and test its behavior.
3. Ubuntu 24.04 build and end-to-end private store/socket verification remain incomplete. Previous proot trial started an executable on glibc 2.39 but failed filesystem metadata operations and private store verification; it does not constitute compatibility evidence. Build and verify in a functioning Ubuntu 24.04 environment, including indicator count, EICAR, Unix socket and JSON response, and no public ports.
4. The comprehensive actual-EICAR automated regression matrix, source review and publication steps are incomplete. No source commit SHA or private release URL exists for these uncommitted changes. Prior tested package remains available for rollback.

RaxoSentinel can scan using its database and built-in rules without invoking ClamAV for the scan path; no claim of complete independence across optional updater tooling is made. No unattended updater was enabled.
