6. Database and lookups
No genuine RSIDB was compiled or verified and no genuine hash lookup was performed. Existing offline tests exercise a synthetic response and lookup only. The importer retains both the complete response and accepted metadata inside provenance in the RSIDB. This duplicates information and increases index size and memory footprint; retain the raw source evidence privately in a separate restricted file with a response digest and acquisition metadata in the database when a safe sidecar design is implemented and validated. Evidence stored this way would still not be an upstream cryptographic signature. Timestamp validation currently checks only nonempty bounded strings, not valid calendar timestamps; live validation must address this before trusting imported records. Duplicate and invalid counts are currently combined.
