## 1. Baseline State Inspection & Bootstrap Defect Resolution

### 1.1 Root Cause of Initial Zero-Indicator Status
During Phase 2D.7 initial testing, `raxosentinel db update --status` showed:
```
CONFIGURED INTELLIGENCE SOURCES:
  Source: ClamAV [clamav]
    Indicators Tracked   : 0
    Source Version       : 
  Source: MalwareBazaar [malwarebazaar]
    Indicators Tracked   : 0
    Source Version       : 
```
**Investigation & Finding:**
This was determined to be a **state-bootstrap defect**:
- In Phase 2D.6, `populate_unified_rsidb` compiled `phase2d6-unified` (`registry.json`, `associations.json`, `evidence-*.json`, `database.rsidb`), but `update_status.json` did not exist prior to Phase 2D.7.
- When `UpdateStatus::load()` executed without an existing `update_status.json`, it created default empty records (`indicator_count = 0`, `source_version = ""`).
- Because `source_version` was empty, the check logic incorrectly believed no upstream version had ever been acquired.

### 1.2 Implemented Resolution
- Enhanced `UpdateStatus::load()` in `crates/raxosentinel-signatures/src/rsidb/updater/status.rs` with `bootstrap_from_generation()`:
  - Detects active generation metadata directly from `registry.json` and evidence sidecars.
  - Automatically initializes `clamav` status (541,953 indicators, version `daily-28173`, timestamp 1793725600).
  - Automatically initializes `malwarebazaar` status (104 indicators, version `d2300809129287f38a81efb68d72d2d5ace982087b65be00968a52e135fe2b94`, timestamp 1793652171).
  - Populates baseline `UpdateSummary` metrics (542,057 indicators, status PASS).
- Enhanced `ClamAvProvider::detect_version()` in `crates/raxosentinel-signatures/src/rsidb/updater/providers/clamav.rs`:
  - Parses official `ClamAV-VDB:...:<version>:...` headers from unpacked `daily.info` and `main.info`.
  - Accurately returns official Cisco Talos distribution versions (e.g. `daily-28173`).
- Hardened `UpdateEngine::apply_update()` in `crates/raxosentinel-signatures/src/rsidb/updater/engine.rs`:
  - Replaced permissive `if let Ok((reg, assoc)) = unified::inspect(...)` with strict fail-closed error propagation. If the existing active generation cannot be inspected, the update terminates immediately, preventing accidental loss of baseline indicators.
